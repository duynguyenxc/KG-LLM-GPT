## Output contract

1. **Source layer:** paper identity, availability, page text, file hash and study-family identity.
2. **Entity/relation layer:** distinguish a semantic entity mention, a canonical concept, a conditional relation assertion, an attribution edge and a retrieval-similarity edge. Expose supporting observations and inference status. Do not merge opposing outcomes or erase time/comparator qualifiers.
3. **Finding layer:** C/resource/response/O, polarity, comparator, follow-up, quotations and measured/inferred/missing labels. Preserve excluded findings and audit reasons.
4. **Synthesis layer:** conditional explanations with evidence IDs, rivals and unresolved gaps; freeze before external comparison.
5. **Evaluation layer:** entity recovery, relation recovery and whole-configuration correspondence are separate tasks. Source-support precision is separate from all three. Human cells remain blank until supplied by actual reviewers.
6. **Presentation layer:** one entry page that identifies the run and completion state, opens actual records, shows graph semantics, and links claims to original sources. JSON/CSV files accompany the readable view.

The current evidence-graph representation is useful for provenance but is not a substitute for semantic relation extraction.
